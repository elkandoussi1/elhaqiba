ميزات القالب

29 صيغة كتابة… جاهزة في كل مقال

كل ما يدعمه قالب elkandoussi داخل المقالات: صور وجداول وأكواد وأزرار وفهارس وغيرها. لكل ميزة شرح مختصر وصيغة كتابة جاهزة للنسخ.

قبل أن تبدأ

أغلب هذه الميزات تكتب في وضع عرض HTML داخل محرر مشاركات Blogger، وبعضها لا يسمح بالرجوع إلى عرض الإنشاء بعد إضافته.

  1. افتح المقال في محرر المشاركات.
  2. انقر أيقونة القلم أسفل يمين العنوان، فيظهر خياران: عرض HTML وعرض الإنشاء.
  3. اختر عرض HTML، ثم الصق صيغة الميزة في مكانها من المقال.

نصيحة: ضع كل فقرة داخل الوسم <p>...</p>.

صورة مع تسمية توضيحية وتكبير تلقائي

Image Caption & Auto Lightbox

كل صور المقال تكبر تلقائيا عند النقر عليها (Lightbox). التسمية التوضيحية أسفل الصورة لا تدخل في وصف المقال ولا في مقتطفه.

الفئة class='full' تزيل الهامش بين الصورة وحافة الشاشة، وتعمل في الهاتف فقط.

صيغة الكتابة
صورة مع تسمية توضيحية
      <table class='tr-caption-container'>
  <tbody>
    <tr>
      <td>
        <img alt='image_title_here' class='full' src='https://4.bp.blogspot.com/.../name.png'/>
      </td>
    </tr>
    <tr>
      <td class='tr-caption'>Your_caption_is_here</td>
    </tr>
  </tbody>
</table>

صناديق الأكواد 3

عرض الأكواد البرمجية وتلوينها ونسخها

تلوين الأكواد البرمجية

Syntax Highlighter

صندوق لعرض أكواد HTML وCSS وJavaScript وغيرها. يمكن تلوينها يدويا، أو تلقائيا بإضافة الفئة hl التي تستعمل مكتبة Highlight.js.

إذا لم يتعرف التلوين التلقائي على لغة الكود، أضف اسمها بجانب hl، مثل language-html أو language-javascript.

صيغة الكتابة 3 أنماط
صندوق كود عادي
<!--[ Change data-text to .html, .css, .js or any language ]-->
<div class='pre pu notranslate' data-text='.html'>
  <pre style='white-space:pre-wrap; max-height:none;'>Your_code_is_here</pre>
</div>
تلوين تلقائي
<!--[ Add a classname hl to automatically color syntax ]-->
<div class='pre hl notranslate' data-text='.html'>
  <pre style='white-space:pre-wrap; max-height:none;'>Your_code_is_here</pre>
</div>
تلوين تلقائي مع تحديد اللغة
<!--[ Add a classname hl to automatically color syntax ]-->
<div class='pre hl language-javascript notranslate' data-text='.js'>
  <pre style='white-space:pre-wrap; max-height:none;'>Your_code_is_here</pre>
</div>

صندوق الأكواد متعدد الوظائف

جديد

صيغة الكتابة
صندوق متعدد الوظائف
<!--[ Replace data-text with any name to show, data-file with filename, data-lang with file extension, data-time with countdown in seconds ]-->
<div class='pre pu notranslate' data-time='5' data-text='Codebox Writing Format' data-file='Typography Codebox' data-lang='.html'>
  <pre style='white-space:pre-wrap; max-height:none;'>Your_code_is_here</pre>
</div>

الروابط الخارجية

External Link

أيقونة صغيرة تنبه القارئ إلى أن الرابط سيفتح موقعا آخر. يتوفر نمطان.

صيغة الكتابة
رابط خارجي
<a class='extL' href='#' rel='noreferrer' target='_blank'>Sample_external_link</a>
<a class='extL alt' href='#' rel='noreferrer' target='_blank'>Sample_link_alt</a>

أزرار الروابط

Button Link

حول أي رابط إلى زر: نمط أساسي، ونمط بإطار، وأزرار بأيقونات جاهزة أو بأيقونات SVG، وزران في سطر واحد.

لتصبح أيقونة SVG بيضاء أضف لها style='fill:#fff; margin-right:12px;' أو style='stroke:#fff; margin-right:12px;'.

صيغة الكتابة 5 أنماط

<a class='button ln' href='url_is_here'>Title_link</a>
زر بأيقونة
<a class='button' href='url_is_here'><i class='icon dl'></i>Title_link</a>
<a class='button' href='url_is_here'><i class='icon demo'></i>Title_link</a>
